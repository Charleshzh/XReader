# XReader 使用手册

## 安装

### Windows

从 [Releases](https://github.com/Charleshzh/XReader/releases) 下载 `.msi` 安装包，双击安装。

### macOS

如 Releases 页面提供 `.dmg` 安装包，下载后拖入 Applications 文件夹。

### Linux

如 Releases 页面提供 `.AppImage` 安装包，添加执行权限后运行：

```bash
chmod +x XReader*.AppImage
./XReader*.AppImage
```

当前仓库 CI 已包含 macOS / Linux 构建任务；是否对外发布安装包以 Releases 页面为准。

## 导入书籍

支持 EPUB、TXT、PDF 格式。

1. 点击书架右上角 **+ 导入** 按钮
2. 选择本地文件（可多选）
3. 书籍自动解析封面、目录、章节信息
4. 支持 GBK/UTF-8/Big5 编码的中文 TXT 文件

---

## 阅读

### 打开书籍

点击书架上的书籍卡片即可打开。

### 阅读模式

- **滚动模式**：上下滑动连续阅读，进度自动保存
- **翻页模式**：点击页面左侧 30% 上一章，右侧 30% 下一章

### 阅读设置

点击右上角设置图标打开面板：

- **字号**：滑动条 10-32px
- **行高**：滑动条 1.0-3.0x
- **字体**：系统默认/宋体/黑体/楷体/等宽
- **主题**：亮色/暗色/护眼
- **模式**：滚动/翻页

所有设置自动保存。

### 目录导航

点击左上角目录图标查看章节列表，点击跳转。

### 键盘快捷键

- `←` / `→`：上一章/下一章

## 书签与笔记

### 添加书签

1. 点击顶部书签图标 📑
2. 输入书签名称（可选）
3. 点击 + 添加

### 查看书签

点击书签图标打开面板，点击书签跳转到对应位置。

### 高亮与笔记

1. 在阅读器中选择文本
2. 点击高亮图标 🖍
3. 选择颜色（黄/绿/蓝/粉/橙）
4. 在高亮面板中可添加笔记

### 导出

书签和笔记面板底部有 **导出** 按钮，保存为 Markdown 文件。

## 发现书籍

1. 点击书架上的指南针图标 🧭
2. 选择一个已导入的书源
3. 浏览推荐/排行榜列表
4. 翻页查看更多

## 书源管理

### 导入书源

XReader 完全兼容 [Legado (阅读)](https://github.com/gedoor/legado) 书源格式：

1. 点击书架上的书源图标 🌐
2. 粘贴书源 JSON
3. 点击导入

### 搜索书籍

1. 点击书架上的搜索图标 🔍
2. 选择书源，输入关键词
3. 点击搜索

## 云同步

支持 WebDAV 协议（坚果云/Nextcloud/ownCloud）。

1. 打开设置页面
2. 填写 WebDAV 地址、用户名、密码
3. 点击同步

同步内容：书架数据、阅读进度、书签、笔记、书源。
策略：增量时间戳同步，本地最新优先，密码加密存储。

## 常见问题

**Q: TXT 文件乱码？**  
A: 程序自动检测 GBK/UTF-8/Big5 编码。如仍有乱码，请将文件转换为 UTF-8 后重新导入。

**Q: 书架不显示封面？**  
A: 部分 EPUB 内嵌封面可能无法提取，显示为文字标题，不影响阅读。

**Q: 导入书源后搜索无结果？**  
A: 书源网站可能已变更、需要网络连接、或触发了反爬机制。尝试其他书源。

**Q: 如何获取书源 JSON？**  
A: 可从 [Legado (阅读)](https://github.com/gedoor/legado) 及其社区维护的兼容书源集合获取 JSON 文件。

## 隐私说明

- 所有数据存储在本地 SQLite 数据库
- 云同步密码使用 ChaCha20-Poly1305 加密存储
- 不上传任何数据到第三方服务器
- 书源搜索使用本地规则引擎直接访问目标网站
